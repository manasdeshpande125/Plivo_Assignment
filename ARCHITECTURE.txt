# Architecture Diagram

## Overall Pipeline

```
┌─────────────────────────────────────────────────────────────────┐
│                      DATA GENERATION                             │
│                                                                  │
│  Templates + Entity Generators → Noisy STT Transcripts          │
│  "my card is {CREDIT_CARD}"                                     │
│  → "my card is four two four two four two..."                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                       TOKENIZATION                               │
│                                                                  │
│  Text → WordPiece Tokens + Offset Mapping                       │
│  Character-level BIO tags → Token-level BIO tags                │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                         MODEL                                    │
│                                                                  │
│  ┌─────────────────────────────────────────────────────┐        │
│  │  INPUT EMBEDDING                                     │        │
│  │  [CLS] my card is four two ... [SEP]                │        │
│  └──────────────────┬──────────────────────────────────┘        │
│                     ↓                                            │
│  ┌─────────────────────────────────────────────────────┐        │
│  │  DistilBERT ENCODER (6 layers)                      │        │
│  │  • Self-attention                                    │        │
│  │  • Feed-forward networks                             │        │
│  │  • Layer normalization                               │        │
│  │  Output: (batch, seq_len, 768)                      │        │
│  └──────────────────┬──────────────────────────────────┘        │
│                     ↓                                            │
│  ┌─────────────────────────────────────────────────────┐        │
│  │  DROPOUT (0.3)                                       │        │
│  └──────────────────┬──────────────────────────────────┘        │
│                     ↓                                            │
│  ┌─────────────────────────────────────────────────────┐        │
│  │  BiLSTM (128 hidden units)                          │        │
│  │  • Forward LSTM: captures left context              │        │
│  │  • Backward LSTM: captures right context            │        │
│  │  • Concatenate: (batch, seq_len, 256)              │        │
│  └──────────────────┬──────────────────────────────────┘        │
│                     ↓                                            │
│  ┌─────────────────────────────────────────────────────┐        │
│  │  DROPOUT (0.3)                                       │        │
│  └──────────────────┬──────────────────────────────────┘        │
│                     ↓                                            │
│  ┌─────────────────────────────────────────────────────┐        │
│  │  LINEAR CLASSIFIER                                   │        │
│  │  256 → 15 (num_labels)                              │        │
│  │  Output: (batch, seq_len, 15)                       │        │
│  └──────────────────┬──────────────────────────────────┘        │
│                     ↓                                            │
│  ┌─────────────────────────────────────────────────────┐        │
│  │  CRF LAYER                                           │        │
│  │  • Transition matrix (15×15)                         │        │
│  │  • Viterbi decoding for inference                    │        │
│  │  • Ensures valid tag sequences                       │        │
│  │  Output: BIO tag sequence                            │        │
│  └─────────────────────────────────────────────────────┘        │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                    POST-PROCESSING                               │
│                                                                  │
│  ┌──────────────────────────────────────────────────┐           │
│  │  BIO → SPAN CONVERSION                            │           │
│  │  [B-PHONE, I-PHONE, I-PHONE, O, ...]            │           │
│  │  → [(5, 25, "PHONE")]                            │           │
│  └──────────────────┬───────────────────────────────┘           │
│                     ↓                                            │
│  ┌──────────────────────────────────────────────────┐           │
│  │  VALIDATION RULES                                 │           │
│  │  • Credit Card: 14-20 digit words                │           │
│  │  • Phone: 9-12 digit words                       │           │
│  │  • Email: contains "at" and "dot"                │           │
│  │  • Name: 1-4 words                                │           │
│  │  • Date: has month or year                       │           │
│  └──────────────────┬───────────────────────────────┘           │
│                     ↓                                            │
│  ┌──────────────────────────────────────────────────┐           │
│  │  OVERLAP RESOLUTION                               │           │
│  │  Merge or filter overlapping spans                │           │
│  └──────────────────┬───────────────────────────────┘           │
└─────────────────────┴───────────────────────────────────────────┘
                              ↓
                    FINAL PREDICTIONS
            [(start, end, label, pii_flag)]
```

## Model Architecture Details

```
INPUT: "my card is four two four two"
       ↓
┌──────────────────────────────────────────┐
│ DISTILBERT (66M parameters)              │
│                                           │
│ Layer 1: Self-Attention                  │
│   Query, Key, Value projections          │
│   Multi-head attention (12 heads)        │
│   ↓                                       │
│ Layer 2-6: Same structure                │
│   ↓                                       │
│ Output: Contextual embeddings             │
│   Shape: (batch=1, seq_len=12, dim=768) │
└──────────────┬───────────────────────────┘
               ↓
┌──────────────────────────────────────────┐
│ BILSTM (2M parameters)                   │
│                                           │
│ Forward LSTM:  h1 h2 h3 h4 ... h12 →    │
│ Backward LSTM: h1 h2 h3 h4 ... h12 ←    │
│                                           │
│ Concatenate: [h_fwd; h_bwd]             │
│   Shape: (batch=1, seq_len=12, dim=256) │
└──────────────┬───────────────────────────┘
               ↓
┌──────────────────────────────────────────┐
│ CLASSIFIER (4K parameters)               │
│                                           │
│ Linear: 256 → 15                         │
│ Logits for each label                    │
│   Shape: (batch=1, seq_len=12, dim=15)  │
└──────────────┬───────────────────────────┘
               ↓
┌──────────────────────────────────────────┐
│ CRF (0.2K parameters)                    │
│                                           │
│ Transition scores: 15×15 matrix          │
│ Start transitions: 15 vector             │
│ End transitions: 15 vector               │
│                                           │
│ Viterbi Decoding:                        │
│   Find best path through state graph     │
│   Respects transition constraints        │
│                                           │
│ Output: [O, O, O, B-CREDIT_CARD, ...]   │
└──────────────────────────────────────────┘

Total Parameters: ~68M
Model Size: ~69MB
```

## Training Flow

```
┌────────────────────────────────────────────────────┐
│ EPOCH LOOP (5 epochs)                              │
│                                                     │
│  For each epoch:                                   │
│    ┌─────────────────────────────────────────┐    │
│    │ TRAINING                                 │    │
│    │                                          │    │
│    │  For each batch (16 examples):          │    │
│    │    1. Forward pass                       │    │
│    │       • BERT encoding                    │    │
│    │       • BiLSTM processing                │    │
│    │       • Classification                   │    │
│    │       • CRF loss computation             │    │
│    │                                          │    │
│    │    2. Backward pass                      │    │
│    │       • Compute gradients               │    │
│    │       • Clip gradients (norm ≤ 1.0)     │    │
│    │                                          │    │
│    │    3. Optimizer step                     │    │
│    │       • AdamW update                     │    │
│    │       • Learning rate schedule          │    │
│    │                                          │    │
│    │  Average loss: X.XXXX                    │    │
│    └─────────────────────────────────────────┘    │
│              ↓                                     │
│    ┌─────────────────────────────────────────┐    │
│    │ VALIDATION                               │    │
│    │                                          │    │
│    │  For each dev batch:                    │    │
│    │    • Forward pass (no gradients)        │    │
│    │    • Compute loss                       │    │
│    │                                          │    │
│    │  Dev loss: Y.YYYY                        │    │
│    └─────────────────────────────────────────┘    │
│              ↓                                     │
│    ┌─────────────────────────────────────────┐    │
│    │ CHECKPOINT                               │    │
│    │                                          │    │
│    │  If dev_loss < best_loss:               │    │
│    │    Save model weights                   │    │
│    │    best_loss = dev_loss                 │    │
│    └─────────────────────────────────────────┘    │
│                                                     │
└────────────────────────────────────────────────────┘
```

## Inference Flow

```
INPUT: "call me on nine eight seven..."
         ↓
┌──────────────────────────────────────┐
│ 1. TOKENIZATION                      │
│    • WordPiece tokenization          │
│    • Add [CLS], [SEP] tokens        │
│    • Create attention mask           │
│    • Track character offsets         │
└───────────────┬──────────────────────┘
                ↓
┌──────────────────────────────────────┐
│ 2. MODEL FORWARD PASS                │
│    • BERT encoding                   │
│    • BiLSTM processing               │
│    • Classification logits           │
└───────────────┬──────────────────────┘
                ↓
┌──────────────────────────────────────┐
│ 3. CRF DECODING                      │
│    • Viterbi algorithm               │
│    • Find best tag sequence          │
│    Output: [O, O, B-PHONE, I-PHONE...]│
└───────────────┬──────────────────────┘
                ↓
┌──────────────────────────────────────┐
│ 4. BIO → SPAN CONVERSION             │
│    • Group B-X and I-X tags          │
│    • Map to character offsets        │
│    Output: [(11, 63, "PHONE")]       │
└───────────────┬──────────────────────┘
                ↓
┌──────────────────────────────────────┐
│ 5. VALIDATION                        │
│    • Check digit word count (9-12)   │
│    • Validate span boundaries        │
│    • Filter invalid detections       │
└───────────────┬──────────────────────┘
                ↓
┌──────────────────────────────────────┐
│ 6. OUTPUT FORMATTING                 │
│    {                                 │
│      "start": 11,                    │
│      "end": 63,                      │
│      "label": "PHONE",               │
│      "pii": true                     │
│    }                                 │
└──────────────────────────────────────┘
```

## Why Each Component?

```
┌─────────────────────┬──────────────────────────────────────┐
│ Component           │ Purpose                              │
├─────────────────────┼──────────────────────────────────────┤
│ DistilBERT          │ • Fast contextual encoding           │
│                     │ • 60% faster than BERT               │
│                     │ • Understands word context           │
├─────────────────────┼──────────────────────────────────────┤
│ BiLSTM              │ • Captures sequential dependencies   │
│                     │ • Bidirectional context              │
│                     │ • Better than linear classifier      │
├─────────────────────┼──────────────────────────────────────┤
│ CRF                 │ • Ensures valid tag sequences        │
│                     │ • No B-PHONE after I-EMAIL          │
│                     │ • Structured prediction              │
├─────────────────────┼──────────────────────────────────────┤
│ Post-processing     │ • Validates entity format            │
│                     │ • Boosts precision 10-15%           │
│                     │ • Interpretable rules                │
└─────────────────────┴──────────────────────────────────────┘
```
